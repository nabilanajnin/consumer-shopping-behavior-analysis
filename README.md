# Consumer Shopping Behavior Analysis

## Project Overview
This project explores consumer shopping behavior using survey data. The analysis uses Python to examine shopping preferences, spending patterns, payment methods, demographic characteristics, and factors influencing purchasing decisions.

## Objectives
- Explore consumer shopping habits and preferences.
- Analyze shopping behavior across age groups, countries, and occupations.
- Examine payment methods and shopping locations.
- Investigate consumer attitudes toward discounts.
- Present findings through data visualizations.

## Tools & Technologies
- Python
- Jupyter Notebook
- Pandas
- Matplotlib
- Seaborn

## Dataset
**Source:** [Consumer Shopping Behavior and Buying Survey Dataset — Kaggle](https://www.kaggle.com/datasets/harpartapsingh13/consumer-shopping-behavior-and-buying-survey-dataset/data)

The dataset contains survey responses about consumer shopping behavior and purchasing preferences.

Download the dataset from Kaggle and place the required CSV file in the location expected by the notebook before running the analysis. Please check the dataset's license before redistributing its files.

## How to Run
1. Clone or download this repository.
2. Install Python and Jupyter Notebook.
3. Install the required libraries:
   ```bash
   pip install pandas matplotlib seaborn jupyter
   ```
4. Download the dataset from Kaggle and place the CSV file in the expected location.
5. Open `notebooks/shopping_analysis.ipynb` and run the cells in order.
